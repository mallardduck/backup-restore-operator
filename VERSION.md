# Versions

Rancher Backup (aka `rancher/backup-restore-operator`) uses SemVer locked to Rancher Minor versions.
Each version of Rancher Backup is specifically designed to cover backup of resources in that Rancher Minor version.

The current version compatibility and alignment information is:

| Branch          | Tag       | Rancher                |
|-----------------|-----------|------------------------|
| `main`          | `head`    | `main` branch (`head`) |
| `release/v11.x` | `v11.x.x` | `v2.15.x`              |
| `release/v10.x` | `v10.x.x` | `v2.14.x`              |
| `release/v9.x`  | `v9.x.x`  | `v2.13.x`              |
| `release/v8.x`  | `v8.x.x`  | `v2.12.x`              |
| `release/v7.x`  | `v7.x.x`  | `v2.11.x`              |
